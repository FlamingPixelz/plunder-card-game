# Dead Man's Draw

This is a console based rendition of the card game 'Dead Man's Draw' that is built with C++ using OOP principles

In this game, 2 players take turns drawing cards that activate special abilities that can affect the amount of points you or your opponent recieves, but busting when you draw a duplicate card. The player can stop drawing at any time.
